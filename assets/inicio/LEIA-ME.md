# Fotos do Início do professor

Cada botão do Início ("O que você quer fazer?" e "Para hoje") usa uma foto desta pasta.
Para trocar, suba um arquivo novo com o MESMO nome. Não precisa mexer no código.

Formato: .webp, 800 x 600 px (4:3), até ~80 KB. O assunto deve ficar no centro, porque o card corta as bordas.

| Arquivo | Botão | Foto atual (provisória) |
|---|---|---|
| chamada.webp | Fazer chamada | gestão escolar |
| notas.webp | Lançar notas | relatórios |
| turmas.webp | Minhas turmas | histórias |
| criar-prova.webp | Criar prova | provas |
| provas-online.webp | Provas online | aplicativos |
| corrigir-gabarito.webp | Corrigir gabarito | provas (produzir: celular lendo o cartão-resposta) |
| corrigir-respostas.webp | Corrigir respostas | dicas de IA |
| iniciar-aula.webp | Iniciar aula (card, quando o Maestro não está em destaque) | Maestro |
| aula-destaque.webp | Faixa "Pronto para a aula?" (Maestro em destaque) | professora com tablet e lousa (16:9, definitiva) |
| lousa.webp | Abrir a lousa | vídeos (produzir: lousa digital na sala) |
| atividades.webp | Atividades prontas | atividades |

O navegador guarda as fotos em cache. Depois de trocar, pode levar alguns minutos para aparecer (ou use Ctrl+F5).

## Foto da faixa do Maestro (aula-destaque.webp)

Formato diferente das outras: 16:9, 1600 x 900 px, .webp até ~150 KB.
O rosto do professor deve ficar na metade de CIMA da foto: no celular a faixa mostra só a parte de cima.
